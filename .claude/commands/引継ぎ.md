前の人（別アカウント・別端末）の続きから作業を始めます。次の順で進めてください。

## 1. 最新にする

```
git pull
```

別の端末や GitHub 直アップで更新されていることがあります。必ず先に実行します。

（このフォルダ以外で `/引継ぎ` を打った場合は、全体の入口
`\\srv02\共有\データフォルダ\ユーザー共有用\地主\claudecode\記憶\引継ぎ.md` の
「曲げシミュレーター・曲がるか判定」の節からここへ来ます。）

## 2. 引き継ぎを読む

このリポジトリには**別々のアプリが2つ**あります。引き継ぎも別なので混ぜないでください。

| アプリ | 場所 | 引き継ぎ |
|---|---|---|
| 曲げシミュレーター（本体） | `bending-simulator.jsx` ほか | `\\srv02\共有\データフォルダ\ユーザー共有用\地主\claudecode\曲げシミュレーション\引き継ぎ.md` |
| Z曲げ・コの字 判定（問い合わせ用） | `zu/` | `\\srv02\共有\データフォルダ\ユーザー共有用\地主\claudecode\Z・コの字判定\引き継ぎ.md` |

- 両方の `引き継ぎ.md` の更新日時を見て、**新しいほう**から再開します（ユーザーがどちらか言った場合はそちら）。
- 「いまの状態」と「残っている作業」を読みます。長いので、上から数件と「残っている作業」の表があれば十分です。
- 共有フォルダが開けないときは、会社のネットワークにつながっているかをユーザーに確認します（`\\srv02\...` に直接アクセスしてよい）。

## 3. 一言で伝えてから作業する

**1〜2行で**「前回どこまで進んでいて、今回は何から始めるか」をユーザーに伝えます。長い要約は書きません。
そのうえで、残っている作業のうち次に進めるものに取りかかります。何をするか決めきれないときだけ、ユーザーに短く聞きます。

## 4. 進めたら毎回やる（ユーザーとの約束）

1. 画面（ブラウザ）で動作を目で確かめる。確かめるまで「完了」と言わない
2. 共有フォルダの `引き継ぎ.md` の「いまの状態」「残っている作業」を書き直す
3. commit して push する（この作業については毎回聞かなくてよい）

## 覚えておくこと

- 説明は短く・日本語。数字が3つ以上なら表にする
- 寸法・実績・引き継ぎは共有フォルダへ。公開リポジトリには入れない
- プログラムが使う値（金型・台・片伸び表・中押しの決まりなど）はリポジトリに入れて push する
- ほかの約束は `CLAUDE.md` に全部書いてあるので、迷ったらそちらを見る
